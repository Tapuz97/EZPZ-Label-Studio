EZPZ Label Studio privacy policy

Effective 13 November 2026. Publisher: Gal Mitrani.

EZPZ Label Studio designs labels and sends them to a printer you select. It has no application account, advertising, analytics, or cloud document service.

Your files and templates

PDFs, images, CSV data and templates are processed locally on your device. The application does not upload their contents to a server. The Windows app saves work in its local WebView profile; the web edition uses storage for this website in your browser. Exported files go to a location you choose. Clearing app or browser data can remove saved work; export templates to keep a backup.

Bluetooth and diagnostics

Bluetooth access is used for a printer you explicitly select. Connection details can include device names, operating-system or browser identifiers, signal strength and reported model information. An exported diagnostic file may contain those identifiers. Diagnostics are saved locally only when you request an export; the app does not transmit them to the publisher.

The hosted website

The web edition is hosted by GitHub Pages. GitHub receives ordinary hosting requests, including IP addresses and browser request information, under GitHub's privacy statement. Hosting requests download application files; your uploaded artwork is processed locally and is not included in those requests. The Windows application does not require GitHub Pages to run.

Contact and deletion

Contact gm@galmitrani.com for privacy or support questions. Information you choose to email is used to respond to your request. To remove local data, clear this website's storage or the Windows application's profile. Uninstalling may leave local profile data; export anything you need before removing it.
