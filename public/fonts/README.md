# Bundled emoji font

Noto Emoji 3.002, unmodified monochrome variable font, from Google Fonts.

- Source: https://github.com/google/fonts/tree/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/notoemoji
- Original filename: `NotoEmoji[wght].ttf`
- Local filename: `NotoEmoji.ttf`
- SHA-256: `de6c18832938afc99caf132b39d6a30a19bac7f2e812e28db2535b4608d27551`
- License: SIL Open Font License 1.1; full text in `NotoEmoji-OFL.txt`.

Packaged in the Windows app and web build. Loaded locally before rendering emoji
to the monochrome label canvas; no font CDN or external emoji service is used.
