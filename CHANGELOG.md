# Changelog

## 0.7.3

- Added offline monochrome printing for Unicode emoji and symbols, alongside ASCII emoticons.
- Added a text-toolbar picker for emoji, symbols and emoticons, with insertion at the text cursor.
- Added custom TTF, OTF, WOFF and WOFF2 font uploads in both font selectors.
- Added a persistent local font library and embedded fonts in exported templates.
- Improved text wrapping to preserve joined emoji, flags, skin tones and combining marks.

Windows installer and standalone version: 0.7.3. Microsoft Store submission package: 1.2.3.0.

## 0.7.2

- Fixed frame snapping to the 1 mm grid at different preview sizes and after printing.

## 0.7.1

- Removed enforced D110 artwork margins so full-width label artwork can be tested without automatic cropping or fitting.

## Earlier updates in the 0.7 release series

- Added experimental NIIMBOT D110 (model 2304) printing support.
- Added D110 label-roll catalog lookup when the printer reports a recognized roll identifier.
- Added 12 printer-independent frame styles with visual previews and adjustable thickness.
